NEXSCALE MARKETING AGENCY WEBSITE

Files:
- index.html
- about.html
- contact.html
- style.css
- script.js
- assets/logo.png

IMPORTANT:
1. Replace hello@nexscale.example in script.js with the real email address.
2. Replace hello@nexscale.com and the WhatsApp placeholder in contact.html.
3. Open index.html locally to preview the site.

FREE HOSTING:
Netlify:
- Go to https://app.netlify.com/
- Sign up / log in.
- Choose Add new site -> Deploy manually.
- Drag the entire 'nexscale-website' folder into the upload area.
- Netlify will publish it on a free netlify.app address.

Vercel:
- Go to https://vercel.com/
- Sign up / log in.
- Create a new project and upload/import the project files.
- Deploy.
